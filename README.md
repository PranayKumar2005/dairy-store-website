# 🥛 Sri Hari Hara Dairy Products

A modern, responsive, and user-friendly dairy products website designed for **Sri Hari Hara Dairy Products, Hayathnagar, Hyderabad**.

The website provides customers with an easy way to explore dairy products, add items to a shopping cart, enter delivery details, and place orders directly through **WhatsApp**.

---

## 🌐 Project Overview

**Sri Hari Hara Dairy Products** is a front-end e-commerce-style website created to provide a convenient online ordering experience for local customers.

The website focuses on:

* Clean and attractive UI
* Mobile responsiveness
* Product browsing
* Shopping cart functionality
* Order details collection
* WhatsApp-based ordering
* Store and contact information
* Customer testimonials
* Simple navigation

The project is implemented as a **static website**, so it does not require a backend server or database.

---

## ✨ Features

### 🏠 Landing Page

* Attractive hero section
* Dairy-focused branding
* Quick navigation
* Call-to-action buttons
* Business highlights

### 🥛 Product Catalog

Customers can browse different categories of products, including:

* Milk
* Curd
* Paneer
* Ghee
* Kowa
* Cream
* Butter
* Ice Cream
* Fresh vegetables
* Snacks

Products can be filtered using category buttons.

### 🛒 Shopping Cart

The website includes a client-side shopping cart that allows users to:

* Add products
* Increase or decrease quantity
* Remove products
* View estimated total
* Review the complete order

### 📝 Order Form

Customers can enter:

* Full name
* Mobile number
* Delivery address
* Preferred delivery time
* Payment mode
* Optional special instructions

Required fields are validated before the order is submitted.

### 📲 WhatsApp Ordering

After completing the order form, the website automatically creates a formatted WhatsApp message containing:

* Customer information
* Delivery details
* Selected products
* Quantities
* Estimated total
* Special notes

The message is then opened in WhatsApp for confirmation.

### 📱 Responsive Design

The website is designed to work across:

* Desktop
* Laptop
* Tablet
* Mobile devices

It includes a mobile navigation menu and responsive layouts.

### 📍 Business Information

The website provides:

* Store address
* Owner information
* Phone numbers
* WhatsApp contact
* Working hours
* Bulk/function order information

## 🚀 Getting Started

Since this is a static website, no backend or package installation is required.

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/sri-hari-hara-dairy.git
```

### 2. Open the project

```bash
cd sri-hari-hara-dairy
```

### 3. Run the website

Simply open:

```text
index.html
```

in your browser.

You can also use **VS Code + Live Server** for easier development.

## 📌 Important Notes

This project is a **front-end/static implementation**.

There is currently:

* No backend server
* No database
* No user authentication
* No online payment gateway
* No server-side order management

Orders are communicated through WhatsApp.

Product prices and information are maintained directly in the HTML/JavaScript source.
